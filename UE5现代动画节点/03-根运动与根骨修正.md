# 根运动与根骨修正：Motion Warping、Offset Root Bone

> 两个工具都带有 Root，却修改不同对象：一个改到达外部目标的 Root Motion，另一个管理 Mesh Root 相对胶囊的内部偏差。

## Motion Warping：让一次 Montage 到达指定目标

Motion Warping 是由 Motion Warping Component、Montage Notify State 和 Root Motion Modifier 协作的目标对齐系统。它在 Montage 的指定时间窗内调整 Root Motion，使角色在窗口结束时到达场景位置或朝向。

它的原理是由资产中的 Notify State 定义 `Warp Target Name` 和 Warping Window，组件保存同名目标 Transform。窗口开始后，Root Motion Modifier（例如 Skew Warp）比较动画原位移与目标，在剩余窗口中重新分配平移和旋转。窗口界定了允许修改多少动作：越短或目标差距越大，修正越突兀。

典型应用是翻越对齐障碍物边缘、处决对齐敌人、开门站到交互点、攀爬抓到把手。链路为 `播放前写入 Warp Target → Montage 进入 Notify Window → 窗口内修正 Root Motion`；三处名称必须一致且动画启用 Root Motion。连续行走和脚部贴地没有明确终点，不应交给它。

## Offset Root Bone：让 Mesh 暂时不立刻追随胶囊

Offset Root Bone 是 AnimGraph 节点，用来保留并回收 Mesh Root 相对角色胶囊的位置与旋转偏差。胶囊可即时服从移动、碰撞和输入，网格则短暂保留动画惯性。

它的原理是观察传入 Pose 的 Root Bone 与角色组件之间的差异，并按模式累积、保持、插值或释放。累积让动画位移和转向惯性留在 Mesh，释放让 Mesh 渐进回到胶囊。它不读取外部目标、不移动 Actor，也不补做 Mesh 偏移的碰撞检查，因此偏差必须有明确的回收时机。

典型应用是起步、停止、Pivot 与连续转向中下半身不应瞬间随胶囊转正的 Locomotion 表现。移动阶段允许累积偏差，停止收尾和 Idle 前插值释放。和 Motion Warping 叠加时要同时观察胶囊、Mesh Root 和 Root Motion，避免外部轨迹修正后又额外保留一段 Mesh 位移。
