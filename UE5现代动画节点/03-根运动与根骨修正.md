# 根运动与根骨修正：Motion Warping、Offset Root Bone

> 两个工具都涉及“根”，但一个改变 Montage 到达场景目标的 Root Motion，另一个管理 Mesh Root 相对角色胶囊的内部偏差。

## 先区分作用对象

| 工具 | 修改对象 | 解决的问题 | 常见场景 |
| --- | --- | --- | --- |
| Motion Warping | 指定窗口内的 Montage Root Motion | 让动画末端到达一个外部目标 | 翻越、处决、开门、攀爬边缘 |
| Offset Root Bone | Mesh Root 相对胶囊的 Transform 偏差 | 让胶囊驱动移动仍保留动画中的位移与转向惯性 | 起步、停止、Pivot、连续转向 |

Actor / 胶囊仍由 Character Movement 或 Root Motion 驱动。两者都不是用来取代普通地面移动的工具。

## Motion Warping：在允许的时间窗内对齐目标

Motion Warping 的工作链路由三个部分组成：

1. Montage 中的 Motion Warping Notify State 标出可修正的时间窗口和 Warp Target 名称。
2. 角色的 Motion Warping Component 保存同名目标的位置与旋转。
3. 播放前由蓝图或 C++ 写入目标；窗口运行时，系统修正这段 Root Motion，使角色在窗口末端满足目标约束。

因此目标应在动画开始前或进入窗口前可用，Notify State 也必须覆盖真正允许被拉伸或转向的动作区间。窗口过短时修正会突兀；目标与动画原始位移差异过大时，脚步、速度或碰撞表现也会失真。

Motion Warping 适用于有明确交互终点的 Montage，不适合把连续行走、脚部贴地或任意方向 Locomotion 都塞进一个 Warp Target。它解决的是“这次动作必须到哪里结束”，不是“这一帧姿势是否自然”。

## Offset Root Bone：受控地积累和释放网格偏差

Offset Root Bone 在 AnimGraph 中让根骨相对胶囊保持位置或旋转偏差，并按模式累积、插值或回收。这样角色胶囊可以及时响应输入和碰撞，而网格仍能短暂保留动画中的惯性，例如 Pivot 时下半身未立刻随胶囊转正。

关键是为偏差设定明确的生命周期：什么时候累积、何时暂停、何时渐进回收。若持续累积不回收，Mesh 会长期偏离胶囊；若回收太快，动画惯性又会消失并出现 Pop。

Game Animation Sample 将此节点用于现代 Locomotion 链路，但也记录了实验性限制，例如它不替 Mesh 偏移补做碰撞检查。将它与 Montage 的 Motion Warping 叠用前，要分别查看 Root Motion、Mesh Root 和胶囊的位置，确认没有产生两次位移修正。

## 调试方法

同时可视化胶囊、Root Bone、Mesh 与 Warp Target。若问题只在交互 Montage 出现，先关闭 Motion Warping 检查 Notify Window 与目标；若问题只在移动转换出现，先关闭 Offset Root Bone 检查偏差的累积和释放。不要只看最终脚的位置判断根问题。
