# 接触与 IK：Foot Placement、Leg IK、Full Body IK

> 地面接触先回答“脚应该落在哪里”，IK 再回答“哪些骨骼该怎样移动才能到达那里”。

## 三个节点的边界

| 节点 | 主要职责 | 求解范围 | 不负责的事 |
| --- | --- | --- | --- |
| Foot Placement | 推断脚的支撑、摆动与地面接触，生成稳定的脚部放置结果 | 双脚、腿部定义与骨盆补偿 | 复杂手脚协同、玩法交互目标 |
| Leg IK | 将已知的脚部目标解算到单条腿链 | 一条或多条独立腿链 | 地面检测、支撑时机、资产选择 |
| Full Body IK（FBIK） | 让多个末端目标共同影响骨盆、脊柱和四肢 | 选定根骨以下的整棵骨架 | 自动判断脚何时该锁定或检测地面 |

三者可以串联，但没有必须一起使用的关系。简单的平地行走可能只需 Foot Placement；已有 Trace、Foot Lock 和脚部目标的系统可只用 Leg IK；攀爬、双手持物或全身贴合才值得引入 FBIK。

## Foot Placement：把接触当成一个连续过程

Foot Placement 是 Animation Warping Runtime 的 AnimGraph Skeletal Control。它以腿部定义、动画姿势、角色运动和地面信息为输入，不只是对脚下打一条射线。

```text
动画中的脚部运动 + 腿部定义
             │
             ├─ 判断脚处于支撑还是摆动，并平滑切换
             ├─ 查询可落脚的地面位置和法线
             ├─ 计算脚掌位置 / 朝向及可达性
             └─ 两腿高度冲突时调整骨盆，输出修正后的腿部姿势
```

它解决的核心问题是：角色胶囊继续移动时，支撑脚不能像被传送一样滑走；遇到台阶或斜坡时，双腿又不能因为长度不足而拉直或穿地。节点通过 Plant（支撑）到 Swing（摆动）的状态过渡释放脚，而不是把脚永久钉在世界空间。

实现时要先校对腿链、脚骨轴向、角色尺度、碰撞通道和可检测距离。接触曲线或接触状态若与动画步态不一致，常见结果是脚掌吸附、抖动或过晚释放。若旧系统仍在写 Foot Lock、Foot Offset 或 Pelvis Offset，应关闭同一职责后再对比；两个系统同时补偿同一只脚通常会形成双重锁定。

## Leg IK：执行已确定的脚部目标

Leg IK 是 AnimGraph 的 Skeletal Control。上游给它目标脚骨的 Transform，它再沿大腿—小腿—脚的链条调整关节，使末端尽量到达目标。

它的原理是局部链求解：目标只约束一条腿，解算器在可伸展范围与关节限制内重新分配髋、膝、踝的旋转。目标不可达时，腿仍会受长度和限制约束，因此骨盆高度、目标距离与腿链初始朝向仍是上游系统的责任。

典型链路是：Trace 或 Foot Placement 决定 IK Foot Bone 的目标 → Pose Warping 修正整体步态 → Leg IK 把大腿和小腿接到该目标。这样可以把“接触决策”和“腿链执行”分开调试。

不要把 Leg IK 当作 Foot Placement 的等价替代：它不知道地面法线，也不知道支撑脚什么时候应该固定。只把实时 Trace 的结果直接送入 Leg IK，往往会在角色移动或地面法线跳变时产生脚滑与抖动。

## Full Body IK：多个目标的整体折衷

FBIK 位于 Control Rig Graph，使用 Position Based IK（PBIK）迭代求解。每个 Effector 提出一个期望的末端位置或旋转；求解器沿从根骨到末端的链传播影响，再根据 Bone Settings 中的 Stiffness、Preferred Angle、Rotation Limit 等约束得到一组整体可接受的姿势。

它与 Leg IK 的关键差别不是“精度更高”，而是约束会相互影响：双脚贴在不同高度、双手握住物体时，骨盆与脊柱可以共同让位，而不是四条独立链各自拉扯。动画蓝图通常通过 `Control Rig` 节点运行包含 FBIK 的 Rig。

FBIK 的根骨、参与骨骼和 Effector 应尽量小而明确。把全骨架和大量无关 Effector 都交给求解器会增加成本，也容易让肩膀、脊柱或骨盆出现不希望的代偿。先用脚部 Effector 验证骨盆响应，再逐步加入手或头部约束更容易定位问题。

## 建议的执行顺序

通常先选择基础动画，再做方向、步幅等整体姿势修正，最后做接触与 IK。先锁脚、后改变根骨或步幅，会再次破坏锁点。FBIK 若用于全身交互，应放在它需要看见的最终目标之后，并限制它覆盖的骨骼层；实际顺序仍要通过当前动画图逐项验证。
