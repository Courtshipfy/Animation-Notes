# Animation Notes

用于记录动画技术、实现思路和实验结果的笔记仓库，当前主要围绕 Unreal Engine 中的角色运动与动画系统展开。

## 内容目录

- [`ALS/`](./ALS/)：Advance Locomotion System，记录高级角色移动、状态机、动画蓝图和相关实现细节。
- [`KAI/`](./KAI/)：Kai Locomotion System，记录 Kai Locomotion System 的结构、功能和使用经验。
- [`MotionMatching/`](./MotionMatching/)：Motion Matching，记录动作匹配、姿态搜索、数据库构建和调试方法。

## 笔记约定

每篇笔记尽量包含以下内容：

- 背景与要解决的问题
- 核心概念或工作流程
- 关键配置、代码和资源
- 实验结果与遇到的问题
- 可进一步验证或优化的方向

这是一个持续整理中的个人技术笔记仓库，内容会随着学习和实践逐步补充。
