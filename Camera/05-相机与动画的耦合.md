# 相机与动画的耦合

> 相机不是动画系统的下游：它的 Control Rotation 直接进入 AnimInstance 的 ViewState，反过来驱动脊柱和头部姿势。

## Control Rotation → ViewState

ALS 的 `AlsAnimationInstance::RefreshView()` 每帧用相机视角与角色朝向的差，计算视角相关状态：

- `ViewYaw = ViewRotation.Yaw - CharacterRotation.Yaw`
- `ViewPitch = ViewRotation.Pitch - CharacterRotation.Pitch`
- 俯仰被归一化成 `PitchAmount = 0.5 - ViewPitch / 180`

这些量驱动 Aim Offset、脊柱旋转和头部朝向（详见 [ALS/07 瞄准与 Overlay](../ALS/07-瞄准与Overlay.md)）。也就是说，**相机看哪里，角色上半身就朝哪里偏**，这是 3C 中 Camera 反哺 Character 动画的关键链路。

## RotationMode 与相机

角色朝向规则（RotationMode）决定角色是朝速度方向、还是朝视角方向：

- `VelocityDirection`：角色持续对齐速度方向，相机独立转动；适合常规跑动。
- `ViewDirection`：角色对齐视角方向，相机转动会带动角色转向。
- `Aiming`：角色朝向被限制在视角附近，相机仍由鼠标直接控制，角色上半身通过 ViewState 微调瞄准。

RotationMode 切换是相机与角色解耦 / 耦合程度的选择：跑动时完全解耦，瞄准时通过角度约束重新耦合（详见 [ALS/04.3 移动方向与 Rotation Yaw Offset](../ALS/04.3-移动方向与RotationYawOffset.md)）。

## 姿态驱动取景

相机的高度、距离、FOV 会随角色姿态变化，保证画面中角色取景稳定：

- 蹲伏时相机降低（`CameraHeight` 变化），站立时恢复。
- 瞄准时拉近（`CameraDistance` 减小）或收窄 FOV。
- 冲刺时可放大 FOV 增强速度感。

在 Refactored 里这些就是 `CameraBehavior` / `CameraHeight` / `CameraDistance` / `CameraFov`，由角色状态或动画层驱动。

## 常见问题

- **相机转动带动角色不想要的转身**：先检查 RotationMode 是否错误切到 ViewDirection，而不是直接怀疑相机。
- **瞄准时头部 / 脊柱过度偏转**：确认 ViewState 的 Yaw / Pitch 是否来自正确的相机旋转，以及是否与 Aim 资源烘焙的偏转叠加（双重旋转）。
- **蹲伏 / 瞄准时取景变化突兀**：确认相机高度 / 距离 / FOV 是否走了延迟，而不是直接赋值。
