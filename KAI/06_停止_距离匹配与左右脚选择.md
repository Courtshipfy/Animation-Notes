# Kai Locomotion：停止——距离匹配与左右脚选择

> 停止要连续回答三个问题：选哪个脚相和方向的停止动作、预测还会滑多远、从哪一帧开始播。贯穿始终的前提是——停止动画的距离曲线是负值：0 是停止点，负值表示离停止点还差多少，与起步/循环的正值曲线相反。

## 解决的问题

角色松开输入后速度不会立刻归零，而是由移动组件按制动摩擦减速滑行。如果停止动画总从同一帧硬播，脚步会与真实减速距离错位；如果忽略当前支撑脚，还可能出现重脚或脚底滑动。停止需要两件事：把动画对齐到「预测的剩余滑行距离」，并按抬起的脚选版本。

## 全貌：一个前提，三步走

理解停止，先记住一个前提：**停止动画的距离曲线是负值**。普通（起步/循环）距离曲线是「从 0 开始的累计位移」，正值；停止曲线在缓存时被翻转成「离停止点还差多少」，0 在结尾、负值在前面。所以 `GetTimeAtDistance(-StopDistance)` 的意思是「找到还剩 `StopDistance` 要滑的那一帧」。

在这个前提下，停止分三步：

1. **选资源**：按速度卡迪纳尔方向、步态、左右脚、蹲伏选停止动画。
2. **预测停止距离**：`PredictGroundMovementStopLocation()` 用制动摩擦 + 制动减速度算「还会滑多远」。
3. **距离匹配**：Setup 把动画定位到 `GetTimeAtDistance(-StopDistance)`；Update 每帧更新预测，接近结尾时切出。

## 工作方式

### 选资源：速度方向 + 步态 + 左右脚 + 蹲伏

进入停止时读取 `LeftFootUpCurve`（`KLSLeftFootUp`）得到 `IsLeftFootUp`，再以**速度卡迪纳尔方向**、当前步态、左右脚和蹲伏状态选择停止动画。

- 方向取速度方向，**不是输入方向**：松开输入时没有可靠的当前输入方向，Kai 依据残余速度方向。
- 步态按 Walk / Run / Sprint 选停止集。
- 若该集启用 `UsePerFootStop` 且左脚抬起，取 `LeftFootUp`，否则取 `RightFootUp`；每向（前/右/左/后）各有左右脚两套。
- 蹲伏用 `CrouchAnimSet.Stops`，逻辑相同、资源与阈值独立。

### 预测停止距离

`PredictGroundMovementStopLocation()` 用移动组件的制动参数做减速外推：

- 制动摩擦 = `GroundFriction`（或单独的 `BrakingFriction`）× `BrakingFrictionFactor`；
- 加上 `BrakingDecelerationWalking`，算出一段「速度 → 0」的滑行轨迹；
- 再做一次胶囊体 trace，把预测落点收敛到可站立的表面上。

得到的 `StopDistance` 就是「胶囊体从当前位置到停止点还要滑多远」。

### 距离匹配定位与更新

Setup 时，把动画直接定位到与预测剩余距离对应的帧：

```text
StopDistance = PredictGroundMovementStopLocation().Length()
SetExplicitTime(GetTimeAtDistance(-StopDistance))
```

进入 Update 后，只要角色没有重新加速，每帧重算预测距离，交给 `DistanceMatchToTarget()`：它按「当前动画时间距停止点是否已越过 `StopDistanceThreshHold`」以及「是否仍在移动」决定继续把动画重定位到预测距离对应的帧，还是按正常速率推进。动画时间推进到结尾前 0.2 秒时设置 `StandingStopBlendToLoop`，交回状态图进入后续状态。

一旦检测到重新加速，停止更新直接返回，不再继续距离匹配，避免把减速动作错误推进到新起步过程。

## 实现要点

- 停止动画的距离曲线是距离匹配的前提；无曲线或曲线与实际 Root 位移不一致时，显式时间定位会失真。
- `LeftFootUpCurve` 的语义必须与动作资源的 Left / Right Foot Up 配置一致；它是选动画的输入，不是纯调试曲线。
- 停止的终点由 Movement Component 的预测决定；修改制动、摩擦或最大速度后，应重新观察停止距离与曲线是否仍匹配。
- 停止曲线约定为负值（0 = 停止点）；用正值思维读 `GetTimeAtDistance(-StopDistance)` 会得到相反的时间。

## 常见问题

- **用输入方向选停止动作。** 松开输入时没有可靠的当前输入方向，Kai 依据的是残余速度方向。
- **只配置一个脚相版本却保留 `UsePerFootStop`。** 选择器会按曲线请求两套数据；缺失资源会造成选择错误或空资产。
- **把停止距离阈值当作动画长度。** 它传给距离匹配逻辑以判断如何接近目标，不是 Sequence 的播放时长。
- **把停止曲线的负值当成 bug。** 负值是有意约定：0 是停止点，负值表示离停止点还差多少，`GetTimeAtDistance` 用负参数反查。
