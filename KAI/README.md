# Kai Locomotion System

记录 Kai Locomotion 3.5.0（UE 5.8）的系统结构、动画逻辑与验证结论。笔记以插件随附的资源和 C++ 源码为准；蓝图图表中的具体连线会在后续通过编辑器资源核对后补充。

## 阅读顺序

1. [系统架构与资源入口](./01_系统架构与资源入口.md)：先定位运行时模块、动画蓝图层和示例资源。
2. [角色移动组件：旋转与网络同步](./02_角色移动组件_旋转与网络同步.md)：理解动画表现依赖的移动、朝向和同步数据。
3. 地面状态专题：输入与朝向模式 → 靶向/非靶向起步 → 循环 → 停止 → Pivot → Turn in Place → 蹲伏。
4. [空中状态：落地预测与落地表现](./10_空中状态_落地预测与落地表现.md)：起跳、顶点、落地预测、下落循环与落地，以及自定义跳跃选择。
5. 分层与姿势修正：姿态叠加与分层 → 瞄准与 Aim Offset → Warping → Foot Placement → Mask/RandomPlayer/Slot → 动画数据与制作约定。

- 只记录直接影响动画表现的角色移动、旋转和网络同步逻辑。
