# 04.4 Grounded Lean

> Grounded Lean 将角色当前的加速或制动转换为局部前后、左右倾斜量，并通过半衰期插值让姿势变化既有响应速度又不会抖动。

## 这篇笔记解决什么问题

仅根据速度播放移动循环，角色容易像“平移的模型”：开始移动和停止时没有重量感，转向时上半身也缺少惯性。Lean 不直接改变角色的实际运动，而是把运动变化转换成动画姿势的辅助参数：

- `ForwardAmount`：局部前后方向的倾斜量；
- `RightAmount`：局部左右方向的倾斜量。

两个值大致归一化到 `-1..1`，正负方向由角色局部坐标决定。动画图可以把它们用于控制躯干、骨盆、胸口或整层姿势的倾斜。

## 从加速度到 Lean

```text
世界空间加速度、速度
          │
          ├─ 点积判断：加速还是制动
          │
          ├─ 选择最大加速度或最大制动减速度
          │
          ├─ 世界空间 → 角色局部空间
          │
          └─ 按对应最大值归一化
                    │
                    └─ Forward / Right Lean
                              │
                         半衰期插值
                              │
                         动画图使用
```

`GetAccelerationAmount()` 的目标不是保存物理单位，而是得到动画容易使用的比例：

```text
目标 Lean ≈ 局部加速度 / 当前阶段的最大加速度
```

如果结果超过单位范围，会通过向量长度限制收敛到 `-1..1`。

## 如何区分加速与制动

代码使用加速度与速度的点积：

```text
Acceleration · Velocity >= 0  → 认为正在加速
Acceleration · Velocity <  0  → 认为正在制动
```

直观地说：

- 加速度与速度同向，速度正在增大，使用 `MaxAcceleration` 归一化；
- 加速度与速度反向，速度正在减小，使用 `MaxBrakingDeceleration` 归一化。

这样处理很重要，因为角色通常允许“加速”和“刹车”使用不同的运动参数。如果始终除以最大加速度，刹车阶段的 Lean 强度就会与实际制动能力不匹配；如果始终除以制动减速度，起步倾斜又会失真。

在速度接近零、或者对应最大值没有有效设置时，函数直接返回零向量，避免用无效的除数制造异常姿势。

## 为什么要转换到局部空间

世界空间加速度只说明加速度朝世界坐标的哪个方向，动画真正需要的是“相对角色身体的前后左右”。因此，代码使用角色当前的旋转把加速度反变换到局部空间：

```text
LocalAcceleration = CharacterRotation⁻¹ × WorldAcceleration
```

例如角色面向世界北方时，向北加速是局部 Forward；角色转向东方后，同样的世界北方加速就可能变成局部 Left 或 Backward。局部空间保证动画参数始终和角色骨骼的前后左右一致。

## 正负值如何理解

通常可以按以下方式理解：

- `ForwardAmount > 0`：向前加速，身体向前压；
- `ForwardAmount < 0`：向后方向的加速度，或向前移动时制动，表现为身体向后回收；
- `RightAmount > 0`：向右加速或向右侧倾斜；
- `RightAmount < 0`：向左加速或向左侧倾斜。

最终画面取决于动画图中的骨骼旋转符号。如果出现“向右移动却向左倒”的情况，优先检查动画图应用的轴向和正负号，而不是直接修改物理加速度。

## Lean 与 Velocity Blend 的区别

这两个参数都来自运动数据，但观察对象不同：

- Velocity Blend 观察“当前速度指向哪里以及各方向占多少”，主要驱动脚步和移动循环的方向混合；
- Lean 观察“速度正在如何变化”，主要表现起步、刹车和转向时的惯性。

角色可以以恒定速度向前移动，此时 Velocity Blend 仍然有明显的 Forward 权重，但加速度趋近于零，Lean 应该逐渐回到零。反过来，角色刚开始加速时速度还不高，Velocity Blend 可能很小，但 Lean 已经可以产生明显的前倾。

## 半衰期插值

`RefreshGroundedLean()` 先得到当前帧的 `TargetLeanAmount`，再根据配置的 `LeanInterpolationHalfLife` 更新已有状态：

```text
Lean = Lerp(PreviousLean, TargetLean, DamperExactAlpha(DeltaSeconds, HalfLife))
```

半衰期表示误差缩小一半所需的时间，而不是“经过多少帧完成”。使用这种阻尼式插值有两个好处：

- 帧率变化时表现更稳定；
- 不会像固定速度插值那样在低帧率下突然跳到目标值。

首次更新或半衰期小于等于零时，直接使用目标值，避免动画实例初始化时继承无效的旧状态。

## 常见问题

### 起步和刹车方向反了

先区分“加速度方向”和“身体倾斜方向”。代码只提供局部加速度的正负，动画图可能为了视觉效果对某一轴取反。确认角色局部轴、骨骼旋转轴以及动画图中的乘法符号是否一致。

### 刹车时倾斜太弱或太强

检查当前项目的最大加速度和最大制动减速度是否合理，并确认点积判断在速度方向快速改变时没有被误解。刹车归一化使用的是 `MaxBrakingDeceleration`，不是 `MaxAcceleration`。

### 低帧率下姿势突然跳变

检查是否误用了固定速度的 `FInterpTo` 或在蓝图中再次覆盖了 C++ 的结果。ALS 使用基于半衰期的精确阻尼插值，就是为了避免大 Delta Seconds 让插值几乎瞬间完成。

### 转向时倾斜方向不自然

转向倾斜来自局部横向加速度，不是单纯读取控制器的 Yaw 变化。应先确认移动组件提供的加速度正确，再检查世界空间到局部空间的旋转是否使用了角色当帧的朝向。
