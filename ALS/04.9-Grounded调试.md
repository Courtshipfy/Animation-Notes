# 04.9 Grounded 调试

> 本章记录 Grounded 动画问题的定位顺序和常见现象。

## 本章范围

- 从 Movement Mode 到最终姿势的逐层检查。
- Grounded、Speed、Gait、Stance 和 Direction 的区分。
- Velocity Blend、Stride Blend 和 Play Rate 的观察方法。
- 起步、停止、Pivot 和转身问题的定位边界。
- 使用动画曲线、调试绘制和源码断点定位问题。

## 推荐检查链

```text
Movement Mode
    → LocomotionMode
    → LocomotionState
    → GroundedState
    → Standing / Crouching State
    → AnimGraph 分支
    → 最终姿势修正
```
