# ALS Foot IK

> Foot IK 让脚部适配实际地面，Foot Lock 保持支撑脚的位置，Pelvis Offset 则负责维持合理腿长。

## 专题导航

- [08.1 脚部 IK 锁定](./08.1-脚部IK锁定.md)：动画曲线如何锁住支撑脚，以及角色移动和旋转产生的偏移如何被补偿。
- [08.2 Foot Offset](./08.2-FootOffset.md)：Foot Offset Trace 与位置/旋转偏移节点如何让脚贴合斜坡、台阶和不规则地面。

## 工作方式

1. 根据动画曲线决定每只脚何时启用 IK 和脚锁定。
2. 向脚部下方检测地面，读取接触点和地面法线。
3. 计算脚部位置与旋转偏移，并根据权重应用到骨骼或 Control Rig。
4. 根据双脚目标高度计算 Pelvis Offset，减少腿部过度拉伸。
5. 脚锁定时保存脚的目标位置，并补偿角色移动和旋转造成的偏移。
6. 角色进入 In Air、Ragdoll 或特殊动作时逐渐降低 IK 权重。

## 常见职责

- **Foot Offset**：让脚贴合斜坡、台阶和不规则地面。
- **Foot Lock**：在支撑阶段保持脚的位置，减少脚滑。
- **Pelvis Offset**：根据双脚高度调整骨盆。
- **Dynamic Transition**：在动作切换或接触变化时平滑过渡。

## 常见问题

- IK 权重没有随动画曲线启停，导致脚在空中继续修正。
- 地面检测距离或碰撞通道不正确，导致脚部目标点错误。
- Pelvis Offset 没有限制范围，导致角色出现异常下蹲。
- 脚锁定目标没有跟随角色旋转补偿，导致支撑脚滑动。
