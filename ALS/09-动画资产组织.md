# ALS 动画资产组织

> 不同动画资产解决不同类型的问题，清晰的职责划分可以减少动画图和状态机的复杂度。

## 资产职责

| 资产 | 主要职责 |
| --- | --- |
| Animation Sequence | 提供 Idle、Start、Cycle、Stop、Turn 等基础动作 |
| Blend Space | 组织速度、方向等连续维度 |
| Aim Offset | 组织瞄准角度的 Additive Pose |
| Animation Curve | 提供步态、脚锁定、IK 和过渡控制 |
| Anim Layer / Linked Anim Graph | 拆分武器、上半身和特殊动作 |
| Anim Slot | 承载运行时插入的交互、受击或蒙太奇动作 |

## 组织原则

- 状态机选择动画上下文，不承担所有连续参数的采样。
- Blend Space 处理同一动画族内部的速度和方向变化。
- Curve 表达动作时间轴上的权重和事件。
- Layer 和 Slot 负责把可复用的局部动作叠加到基础姿势。
- 替换角色骨骼或增加武器姿势时，尽量只影响对应资产层。
