# ALS 调试问题

> ALS 的视觉问题通常沿着“数据 → 状态 → 姿势 → 局部修正”的链路传播。

## 推荐顺序

1. **数据**：AnimInstance 是否拿到了正确的角色引用？Speed、Direction、Gait、Stance 等变量是否正确更新？
2. **状态**：状态机是否进入预期的 Grounded、In Air 或 Ragdoll 分支？过渡规则是否被阈值阻断？
3. **姿势**：Blend Space 的轴范围、样本方向、播放速率和动画剩余时间是否合理？
4. **分层**：Aim Offset、Overlay、Anim Slot 是否作用于正确的骨骼层级？
5. **修正**：Foot IK、Foot Lock 和 Pelvis Offset 是否在正确状态下启用和降权？

## 常见现象

| 现象 | 优先检查 |
| --- | --- |
| 角色不播放移动动画 | Speed、Should Move、状态机入口 |
| 方向动画错误 | 局部空间转换、Direction、Blend Space 轴 |
| 起步或停止突兀 | 过渡条件、动画剩余时间、方向选择 |
| 上半身动作影响脚步 | 骨骼混合范围、Additive 参考姿势、Layer 权重 |
| 脚滑或脚悬空 | 地面检测、IK 曲线、脚锁定目标、Pelvis Offset |
| 空中仍有脚部修正 | In Air 状态切换和 IK 降权 |

## 记录问题时保留

- 现象：看到了什么问题。
- 条件：角色状态、输入、速度和地形。
- 位置：相关 AnimInstance、AnimGraph、状态机或资产。
- 原因：确认后的根因，而不是猜测。
- 修复：改了什么，以及是否验证有效。
